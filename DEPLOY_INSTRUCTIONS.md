# 🚀 Развёртывание Transcribe App на GitHub Pages

## ⚡ Самый быстрый способ (2 минуты)

### Требования:
1. GitHub аккаунт (бесплатно)
2. GitHub CLI установлен (https://cli.github.com/)
3. Node.js v16+ установлен

### Одна команда для развёртывания:

```bash
bash AUTO_DEPLOY.sh
```

**ВСЁ!** Приложение автоматически:
- ✅ Создаст репозиторий на GitHub
- ✅ Соберёт приложение
- ✅ Загрузит код
- ✅ Включит GitHub Pages
- ✅ Сгенерирует ссылку для команды

---

## 📋 Что получается

После выполнения скрипта вы получите:

```
https://YOUR_USERNAME.github.io/transcribe
```

Вы можете скопировать эту ссылку и отправить своим сотрудникам. Они просто откроют ссылку в браузере и начнут использовать приложение.

**Никаких установок, никаких платежей, никаких лимитов.**

---

## 🎯 Использование (для сотрудников)

1. Откройте ссылку: `https://YOUR_USERNAME.github.io/transcribe`
2. Загрузите видео (перетащите или выберите файл)
3. Выберите модель Whisper (рекомендуем `base`)
4. Нажмите "Начать транскрибацию"
5. Дождитесь окончания
6. Скачайте результат (JSON, SRT или TXT)

### Загрузка с Google Drive (опционально)

1. Откройте видео в Google Drive
2. Поделитесь → Получить ссылку → Копировать
3. В приложении: "Google Drive URL" → вставьте ссылку
4. Приложение автоматически скачает видео

## 🛠️ Ручное развёртывание (если GitHub CLI недоступен)

Если у вас нет GitHub CLI, вот альтернативный способ:

### 1. Создайте репозиторий на GitHub
```
https://github.com/new?name=transcribe
```

### 2. Установите зависимости и соберите приложение
```bash
cd transcribe-app
npm install
npm run build
```

### 3. Инициализируйте git
```bash
cd transcribe-app
git init
git config user.email "transcribe@github.local"
git config user.name "Transcribe"
git add .
git commit -m "Initial commit"
```

### 4. Загрузите на GitHub
```bash
git remote add origin https://github.com/YOUR_USERNAME/transcribe.git
git branch -M main
git push -u origin main
```

### 5. Включите GitHub Pages
1. Откройте: `https://github.com/YOUR_USERNAME/transcribe/settings/pages`
2. Выберите: "Deploy from a branch"
3. Branch: `main`
4. Folder: `/` (root)
5. Save

### 6. Ссылка будет готова через 1-2 минуты
```
https://YOUR_USERNAME.github.io/transcribe
```

## ❓ Часто задаваемые вопросы

### Сколько это стоит?
**Бесплатно!** GitHub Pages предоставляет 1GB хранилища и неограниченный трафик.

### Мне нужен сервер?
**Нет.** Всё работает в браузере пользователя:
- Модель Whisper скачивается один раз и кэшируется
- Видео обрабатывается локально на машине пользователя
- История сохраняется в браузер (localStorage)
- GitHub Pages только раздаёт статические файлы

### Сколько лимитов у GitHub Pages?
- **Хранилище:** 1 GB
- **Трафик:** Неограниченный
- **Скорость:** Быстро (CDN)

Приложение занимает ~180 MB, модели Whisper (~40-2900 MB в зависимости от размера) загружаются один раз.

### Я хочу изменить цвета/стиль
Отредактируйте `transcribe-app/src/App.css`:

```css
/* Найдите эту строку и измените цвета */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* Примеры градиентов:
   - Красный: linear-gradient(135deg, #f093fb 0%, #f5576c 100%)
   - Зелёный: linear-gradient(135deg, #4facfe 0%, #00f2fe 100%)
   - Оранжевый: linear-gradient(135deg, #fa709a 0%, #fee140 100%)
*/
```

Затем обновите:
```bash
cd transcribe-app
git add .
git commit -m "Update colors"
git push
```

### Модели Whisper - какую выбрать?
```
tiny    39MB   ⚡⚡⚡ Супербыстро    (~30 сек на 5 мин видео)
base   140MB   ⚡⚡  Нормально      (~1-2 мин на 5 мин видео)  ← РЕКОМЕНДУЕТСЯ
small  465MB   ⚡    Качественнее   (~3-5 мин на 5 мин видео)
medium 1.5GB  🐢    Медленно       (~10-15 мин на 5 мин видео)
large  2.9GB  🐢🐢  Очень медленно (~20-30 мин на 5 мин видео)
```

Первая загрузка модели займет время, затем будет использоваться кэш.

### История транскрибаций
Все транскрибации автоматически сохраняются в браузер. История доступна в вкладке "История" и сохраняется даже после закрытия браузера.

## 🚨 Возможные проблемы

### "Модель не загружается"
- Проверьте интернет-соединение
- Модель кэшируется, вторая загрузка будет мгновенной
- Если проблема повторяется, попробуйте меньшую модель

### "Видео не загружается"
- Проверьте формат видео (MP4, WebM, Ogg)
- Если используете Google Drive, проверьте доступ к ссылке
- Попробуйте меньший файл для теста

### "GitHub Pages не работает"
- Дождитесь 1-2 минуты после push
- Очистите кэш браузера (Ctrl+Shift+Delete)
- Проверьте настройки Pages в Settings репозитория

### "Ошибка при запуске AUTO_DEPLOY.sh"
Убедитесь, что:
- GitHub CLI установлен: `gh --version`
- Вы вошли в GitHub: `gh auth status`
- Node.js установлен: `node --version`
- npm установлен: `npm --version`
