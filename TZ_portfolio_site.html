1. ОПИСАНИЕ ПРОЕКТА

Создать минималистичный портфолио-сайт для демонстрации видеопроектов (портфолио, галерея, шоурил и т.д.). Сайт должен полностью повторять стиль, дизайн и архитектуру https://egorappolonov.ru

Основная функция: Демонстрация видеопроектов в современном, минималистичном интерфейсе с тёмной темой.

2.2 Типография

  • Заголовки: Unbounded (Google Fonts) — современный, геометричный
  • Основной текст: Manrope (Google Fonts) — чистый, читаемый
  • Код/терминал: JetBrains Mono (monospace)
  • Font-weight: 400 (normal), 600 (bold), 700 (heavy)

2.3 Эффекты и анимации

  • Glitch-эффект: На заголовках при загрузке/hover
  • Плавные переходы: cubic-bezier(0.16, 1, 0.3, 1) (200-300ms)
  • Opacity переходы: Для появления элементов

3. СТРУКТУРА И ФУНКЦИОНАЛЬНОСТЬ

3.1 Разделы сайта

A. HERO SECTION (Главный экран)

  • Большой видеоплеер (720p или Full HD)
  • Заголовок: "SHOWREEL 2025" или название основного видео
  • Описание проекта
  • Длительность видео (0:00 / 1:06)
  • Плакат (preview image) для видео

B. PORTFOLIO GRID (Галерея проектов)

  • Сетка проектов 3-4 колонки (адаптивная)
  • Каждая карточка содержит:
    • Превью видео (обложка)
    • Название проекта
    • Краткое описание (1-2 строки)
    • Длительность видео
    • Клиент / бренд (опционально)
  • При клике на проект:
    • Открывается модальное окно / переход на страницу проекта
    • Воспроизводится видео
    • Показывается полное описание

C. ИНФОРМАЦИОННЫЕ СЕКЦИИ

  • О себе / Студии — текст + фото/видео
  • Услуги / Что мы делаем — список с описанием
  • Контакты — email, Telegram, телефон, форма обратной связи

D. ФУТЕР

  • Copyright
  • Ссылки на социальные сети
  • Контактная информация

5. ТРЕБОВАНИЯ К ВИДЕО И ИЗОБРАЖЕНИЯМ

5.1 Видеофайлы

Параметр Значение
Формат MP4 (H.264 codec)
Разрешение 1280x720 (720p) или 1920x1080 (Full HD)
Битрейт 5-8 Mbps (оптимизировано для web)
Звук AAC, 128 kbps
Максимум размер 50-100 MB (для быстрой загрузки)
Минимум длительность 30 сек

5.2 Изображения для обложек (covers)

Параметр Значение
Формат JPEG или WebP
Размер 1280x720 px (16:9 ratio)
Оптимизация Сжато (80-150 KB)
Содержание Ключевой кадр из видео
