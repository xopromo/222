## 🎯 БЫСТРЫЙ СТАРТ (5 минут)

### 1. Установите Node.js
```bash
# Проверьте версию
node --version  # должно быть 16+
npm --version
```

### 2. Установите зависимости
```bash
cd /home/user/222/transcribe-app
npm install
```
(Это займёт ~3-5 минут)

### 3. Запустите в разработке
```bash
npm start
```
Откроется http://localhost:3000 автоматически

### 4. Тестируйте функции
- Загрузите видео
- Попробуйте Google Drive ссылку
- Выберите разные модели
- Посмотрите историю

## 📱 КАК ИСПОЛЬЗОВАТЬ (для сотрудников)

### Шаг 1: Загрузить видео
```
☑ Способ 1: Перетащить файл в область
☑ Способ 2: Google Drive ссылка
  └─ Откройте видео в Drive
  └─ Поделиться → Общий доступ
  └─ Скопируйте ссылку
  └─ Вставьте в приложение
```

### Шаг 2: Выбрать модель
```
tiny     39MB   ⚡⚡⚡ Быстро      (< 1 мин на 5 мин видео)
base    140MB   ⚡⚡  Нормально   (2-5 мин на 5 мин видео) ← РЕКОМЕНДУЕТСЯ
small   465MB   ⚡    Медленнее   (5-10 мин на 5 мин видео)
medium  1.5GB  🐢    Медленно    (10-20 мин на 5 мин видео)
large   2.9GB  🐢🐢  Очень медл  (30+ мин на 5 мин видео)
```

### Шаг 3: Транскрибировать
```
Нажмите "Начать транскрибацию"
    ↓
Подождите (% показывает прогресс)
    ↓
Получите результат
    ↓
Экспортируйте: JSON, SRT, TXT
```

### Шаг 4: История
```
Всё автоматически сохраняется в браузер
Откройте вкладку "История"
Видьте все прошлые транскрибации
```

## 🔐 ПРИВАТНОСТЬ & БЕЗОПАСНОСТЬ

✅ **ВСЁ локально в браузере пользователя:**
- Видео НЕ отправляется на серверы
- Модель Whisper скачивается один раз и кэшируется
- Обработка происходит на машине пользователя
- История сохраняется в браузер (localStorage)

❌ **GitHub Pages видит только:**
- HTTP запрос на index.html
- JavaScript и CSS файлы
- Больше ничего!

## 🚨 ВОЗМОЖНЫЕ ПРОБЛЕМЫ

### "Модель не загружается"
```
❌ Проблема: Интернет медленный
✅ Решение: Модель кэшируется, второй раз загрузится из кэша
```

### "Видео не загружается с Google Drive"
```
❌ Проблема: Ссылка недоступна
✅ Решение: Откройте видео → Поделиться → Скопируйте новую ссылку
```

### "Приложение медленное"
```
❌ Проблема: Выбрана большая модель (medium/large)
✅ Решение: Используйте base или small
```

### "История не сохраняется"
```
❌ Проблема: localStorage отключён в браузере
✅ Решение: Включите локальное хранилище в настройках
```
