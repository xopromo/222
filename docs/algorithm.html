🗺 Общая схема работы
Скрипт запускается через меню «Автоматизация маркетинга → Запустить анализ проекта» в Google Sheets. Лимит выполнения GAS — 6 минут. Стейт-машина автоматически сохраняет прогресс и перезапускается.

⚙️ Стейт-машина (обход лимита 6 мин)
GAS убивает скрипт через 6 минут. Стейт-машина сохраняет прогресс в скрытый лист «МктСтейт» и позволяет продолжить с того же места при следующем запуске. Максимум автоперезапусков: MAX_CYCLES_ = 10.

phase: compress
Идёт чанковое сжатие контекста Gemini

Анализ ЦА и/или генерация заходов
→ Нет состояния → compress: контекст >80k символов и есть ключ Gemini → сохраняем сырой текст в колонку D листа МктСтейт, начинаем _phaseCompress_
→ compress → analyze: все чанки сжаты → кэш финализирован → если времени мало, сохраняем state{phase:'analyze'} и ждём перезапуска
→ analyze → (нет состояния): все модели отработали → _clearState_() удаляет данные из МктСтейт
🔄 Автоперезапуск: runMarketingAnalysis() читает МктСтейт, если state.cycleCount <= 10 — вызывает _resumeRun_(state), иначе сообщение об ошибке
// runMarketingAnalysis() — точка входа function runMarketingAnalysis() { RUN_START_MS_ = new Date().getTime(); var state = _loadState_(); // читаем МктСтейт if (state && state.phase) { state.cycleCount++; if (state.cycleCount > MAX_CYCLES_) { // MAX_CYCLES_ = 10 _clearState_(); return; } _resumeRun_(state); // продолжаем с той же фазы } else { _startFreshRun_(); // свежий запуск } } // timeIsLow_() — проверка: осталось <4.5 мин function timeIsLow_() { return (new Date().getTime() - RUN_START_MS_) > 270000; // 4.5 мин }

⚡ Постфайловое сжатие (PER_FILE_COMPRESS_ = 25 000 симв.)

Каждый файл >25k символов сразу при чтении сжимается Gemini до ~3k. Это происходит до сборки общего контекста. Позволяет обрабатывать 19+ файлов без накопления гигантского блоба.

function _compressFileText_(text, fileName, settings, state) { if (text.length <= PER_FILE_COMPRESS_ || !settings.geminiKey) return text; var compressed = _compressOneChunk_(text, 0, 1, settings); if (compressed) return '[Сжато из ' + Math.round(text.length/1000) + 'k]\n' + compressed; return text.substring(0, PER_FILE_COMPRESS_) + '\n[⚠️ Обрезано]'; }
Кэш контекста — лист «Кэш»

Ключ кэша = MD5 от списка источников (B3). Если ключ совпадает — пересборка из файлов пропускается, данные берутся из кэша. Для ручного сброса — удалите лист «Кэш».

🗜 Глобальное сжатие контекста
Глобальное сжатие запускается только если суммарный контекст > 80 000 символов после постфайлового сжатия. Groq/Llama поддерживает ~100k контекст (~100 000 символов), поэтому 80k — безопасный порог.
УсловиеДействие
context ≤ 80k симв. Сохраняем в «Кэш» as-is, сразу к анализу
context > 80k, нет ключа Gemini Обрезаем до 80k с предупреждением
context > 80k, есть ключ Gemini Chunked-сжатие: чанки по 3 000 000 символов
_compressOneChunk_(): Gemini + фоллбэк

Prompt-based extraction: продукт, ЦА, спикер, кейсы, кастдевы, цитаты. При Gemini 429/503 — автоматический фоллбэк на kie.ai Gemini 2.5 Flash.

Gemini 2.0 Flash (primary) kie.ai Gemini 2.5 Flash (fallback) maxOutputTokens: 8192
Промежуточное хранение (МктСтейт, колонка D)

Сырой контекст разбивается на чанки по 45 000 символов и записывается в колонку D листа «МктСтейт» (ячейки D1, D2, …). При автоперезапуске восстанавливается из них. Используется SpreadsheetApp, DriveApp не задействован.

💡 Генерация заходов и отбор лучших
Промпт 2a — 5 заходов на сегмент (3 батча)

Для каждой выбранной модели выполняются 3 последовательных API-вызова (bi=0,1,2). Каждый берёт один сегмент из audience_segments и просит 5 заходов разными механиками.

// Цикл по моделям → цикл батчей → retry при 5xx for (var bi = 0; bi < 3; bi++) { for (var ri = 0; ri <= 2; ri++) { // retry: до 3 попыток try { batchRes = callModelApi_(settings, model, buildPrompt2a_(analysisData, bi), 3000); break; } catch (be) { if (ri < 2 && be.message.indexOf('HTTP 5') !== -1) Utilities.sleep((ri+1) * 8000); // 8с, 16с else throw be; } } allHyps = allHyps.concat(batchRes.hypotheses || []); if (bi < 2) Utilities.sleep(2000); // пауза между батчами }

Промпт 2b — отбор 10 лучших из 15

Та же модель получает список 15 заходов и выбирает 10 по критериям: отклик у холодной аудитории, разнообразие сегментов, конкретность хука. max_tokens: 3500.

stripJsonMarkdown_() — устойчивый парсинг

Модели иногда возвращают JSON в markdown-блоке или с буквальными переносами строк. Функция:

  • Извлекает содержимое блока ```json...``` через regex
  • Берёт подстроку от первого { до последнего }
  • Экранирует буквальные \n/\r/\t внутри JSON-строк

Почему kie.ai иногда падает (HTTP 524)

kie.ai проксирует запросы через Cloudflare с таймаутом ~100 сек. Gemini 2.5 Flash успевает за 60–70 сек. Медленные модели (Claude, GPT) при больших запросах превышают лимит. Решение: батчи по 5 гипотез (~2000 токенов = ~35–50 сек).

LLM-пул для анализа (callLlmApi_)

Автоматическое переключение при 429: Groq → Groq2 → Cerebras → Mistral. Если все исчерпаны — ошибка. response_format: json_object обязателен для корректного парсинга.
