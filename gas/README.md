# Автоматизация маркетингового анализа через Groq API

Google Apps Script для автоматического анализа проекта и генерации рекламных гипотез в Google Таблицах.

## Быстрый старт

### 1. Установка скрипта

1. Открой Google Таблицу (или создай новую).
2. Меню: **Расширения → Apps Script**.
3. Удали весь код в редакторе (`Code.gs`).
4. Вставь содержимое файла `marketing_automation.gs`.
5. Нажми **Сохранить** (Ctrl+S / Cmd+S).
6. Закрой редактор и **перезагрузи таблицу** — в меню появится «Автоматизация маркетинга».

### 2. Создание шаблона листов

Меню таблицы → **Автоматизация маркетинга → Создать шаблон листов**.

Будут созданы три листа:
- `Настройки` — API-ключ и ID папки
- `Анализ` — продукт и сегменты ЦА
- `Подготовка к запуску` — рекламные гипотезы

### 3. Настройка

Открой лист **«Настройки»** и заполни:

| Ячейка | Что вставить |
|--------|-------------|
| B2 | API-ключ Groq (получить на [console.groq.com](https://console.groq.com) → API Keys) |
| B3 | ID папки Google Drive с материалами проекта |

> **Как найти ID папки:** открой папку в браузере, ID — это часть URL после `/folders/`  
> Пример: `https://drive.google.com/drive/folders/`**`1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs`**

### 4. Подготовка материалов проекта

Положи в папку Google Drive любые из этих файлов:
- **Google Документы** — лендинг, описание продукта, отзывы ЦА, кастдевы, брифы
- **Текстовые файлы `.txt`** — любой текстовый контент
- **CSV-файлы `.csv`** — данные в табличном формате

Чем больше материалов — тем точнее анализ.

### 5. Запуск

Меню таблицы → **Автоматизация маркетинга → Запустить анализ проекта**.

Скрипт выполнит два запроса к Groq API (~30–60 сек) и заполнит оба листа.

---

## Что делает скрипт

```
Папка Drive → контекст → Groq API
                              ↓
                    Запрос 1: анализ продукта + 3 сегмента ЦА
                              ↓
                    Лист «Анализ» (блок продукта + блок ЦА)
                              ↓
                    Запрос 2: 15 гипотез → выбор 10 лучших
                              ↓
                    Лист «Подготовка к запуску» (10 строк)
```

## Структура выходных данных

### Лист «Анализ»

**Блок продукта** (строка 2, колонки A–H):

| A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|
| Название | О чём | Формат | Оффер | Преимущества | Методика | Посадочная | Спикер |

**Блок ЦА** (строки 5–7, колонки A–I, по одному сегменту на строку):

| A | B | C | D | E | F | G | H | I |
|---|---|---|---|---|---|---|---|---|
| Описание | Уровень Ханта | Боли | Потребности | Возражения | Боль→Решение | Результат | Результат результата | Оффер под сегмент |

### Лист «Подготовка к запуску»

10 строк с рекламными гипотезами (колонки A–C):

| A | B | C |
|---|---|---|
| Сегмент ЦА | Описание | Промо-гипотеза (заход, ключевое сообщение, структура, триггеры, заголовки) |

## Устранение ошибок

| Сообщение | Причина | Решение |
|-----------|---------|---------|
| API-ключ не заполнен | Пустая ячейка B2 | Вставь ключ Groq |
| Не удалось открыть папку | Неверный ID или нет доступа | Проверь ID, выдай доступ скрипту к Drive |
| Groq API вернул ошибку 401 | Неверный или истёкший ключ | Создай новый ключ на console.groq.com |
| Groq API вернул ошибку 429 | Превышен лимит запросов | Подожди 1–2 минуты и повтори |
| Лист «...» не найден | Не создан шаблон | Запусти «Создать шаблон листов» |

Логи выполнения: в редакторе Apps Script → **Просмотр → Журналы** (или Ctrl+Enter).

## Смена провайдера ИИ

Скрипт легко переключается на OpenAI — замени в начале файла:

```javascript
// Было (Groq):
var GROQ_API_URL = 'https://api.groq.com/openai/v1/chat/completions';
var GROQ_MODEL   = 'llama-3.3-70b-versatile';

// Стало (OpenAI):
var GROQ_API_URL = 'https://api.openai.com/v1/chat/completions';
var GROQ_MODEL   = 'gpt-4o';
```

API-ключ в ячейке B2 замени на ключ OpenAI — больше ничего менять не нужно.
