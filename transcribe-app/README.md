# 🎙️ Transcribe App - Бесплатная транскрибация видео

Веб-приложение для транскрибации видео работающее полностью в браузере. Никакие данные не отправляются на серверы.

## ✨ Особенности

- ✅ **Приватность**: Все обработки происходят в браузере
- ✅ **Бесплатно**: Полностью free (нет лимитов, нет платежей)
- ✅ **Offline**: Работает offline после загрузки модели
- ✅ **Быстро**: Выберите модель от 39MB до 2.9GB
- ✅ **История**: Автоматическая история всех транскрибаций
- ✅ **Google Drive**: Поддержка загрузки видео с Google Drive
- ✅ **Экспорт**: JSON, SRT, TXT форматы

## 🚀 Быстрый старт

### 1. Требования

- Node.js 16+
- npm или yarn

### 2. Установка

```bash
cd transcribe-app
npm install
```

### 3. Разработка

```bash
npm start
```

Откройте http://localhost:3000 в браузере

### 4. Deploy на GitHub Pages

1. Отредактируйте `package.json` - измените `homepage` на вашу ссылку:

```json
"homepage": "https://yourusername.github.io/transcribe"
```

2. Создайте GitHub репо `transcribe` в вашем аккаунте

3. Измените origin:

```bash
git remote set-url origin https://github.com/yourusername/transcribe.git
```

4. Deploy:

```bash
npm run deploy
```

5. На GitHub репо включите GitHub Pages:
   - Settings → Pages → Deploy from a branch → main / gh-pages

6. Откройте https://yourusername.github.io/transcribe

## 📝 Использование

### Загрузить видео

1. Перетащите видеофайл в зону загрузки
2. Или нажмите "Выбрать файл"
3. Или вставьте ссылку Google Drive

### Google Drive

1. Откройте видео на Google Drive
2. Нажмите "Поделиться" → "Общий доступ"
3. Скопируйте ссылку
4. Вставьте в приложение

### Транскрибировать

1. Выберите модель Whisper
2. Загрузите видео
3. Нажмите "Начать транскрибацию"
4. Дождитесь завершения
5. Экспортируйте результат (JSON/SRT/TXT)

## 💾 История

Все транскрибации автоматически сохраняются в браузер (localStorage).

- Максимум 50 последних записей
- Видно: имя файла, модель, время, текст превью
- Можно очистить всю историю

## 🔄 Экспорт форматов

### JSON
```json
{
  "text": "полный текст...",
  "segments": [
    { "start": 0, "end": 5, "text": "текст сегмента" }
  ],
  "language": "ru",
  "duration": 123.45
}
```

### SRT (SubRip)
```
1
00:00:00,000 --> 00:00:05,000
Текст первого субтитра

2
00:00:05,000 --> 00:00:10,000
Текст второго субтитра
```

### TXT
Просто весь текст без разметки

## 🔐 Приватность

- ✅ Никакие данные не отправляются на серверы
